# iMessage Bot

Send personalized iMessage to filtered contacts from macOS Contacts. Two-step (scan → review CSV → send). One-shot helper: `send_to.py` for named contacts or a `.vcf` export.

## Usage

### 0. Smoke test (CRITICAL — first time only)
Verify AppleScript send pattern works on your macOS version BEFORE any real run:
```bash
python smoke_test.py +39YOURNUMBER
python smoke_test.py +39YOURNUMBER --from "iMessage;-;+39MITTENTE"
```
- **Scopo:** prova reale verso il **tuo** numero; conferma che Messages/automation funzionano.
- **`--from`:** mittente iMessage (stesso formato di `list_senders.py`). Opzionale: se omesso usa l’account predefinito del Mac.
- **Attenzione:** attendi ~30 s e controlla il telefono. Exit code 0 **non** garantisce consegna.

### Lista account mittente (per `--from`)
```bash
python list_senders.py
```
- **Scopo:** legge `~/Library/Messages/chat.db` e stampa gli ID da usare come `--from` in `smoke_test.py`, `send.py`, `send_to.py`.
- **Requisito:** Full Disk Access al terminale (vedi sotto).

### Scan (rubrica macOS o file .vcf)
```bash
python scan.py
python scan.py --config config.yaml
python scan.py --out /percorso/preview.csv
python scan.py --vcf "/percorso/export.vcf"
```
- **Scopo:** applica il filtro NY da `config.yaml`, rileva lingua/handle iMessage dove possibile, scrive il CSV di anteprima.
- **`--vcf`:** usa un export Contatti invece della rubrica locale (stesso formato usato da `send_to.py`).

### Review
Open `output/preview.csv` in Numbers/Excel. Set `skip_reason` column to exclude rows.

### Send (campagna da CSV)
```bash
python send.py --dry-run
python send.py
python send.py --csv /percorso/altro.csv
python send.py --warmup
python send.py --from "iMessage;-;+39MITTENTE"
```
- **`--dry-run`:** non invia; utile per verificare il flusso.
- **`--csv`:** file diverso da quello in `config.yaml`.
- **`--warmup`:** usa il tetto “primo giorno” (`warmup_first_day_cap`) invece del `daily_cap` pieno.
- **`--from`:** mittente; se vuoto, usa `defaults.from_id` in `config.yaml` o l’account default del Mac.
- **Riprendibile:** i contatti già loggati in `output/sent.json` vengono saltati. Lock file evita due `send.py` in parallelo.

### Send to (messaggio puntuale per nome)
```bash
python send_to.py "Testo messaggio" Nome1 "Nome Due"
python send_to.py --dry-run "Testo" Mazza
python send_to.py --yes --force "Ciao" Mazza Mamma
python send_to.py --vcf "/percorso/All Contacts.vcf" --yes --force "Ciao" Mazza
python send_to.py --sms-fallback "Ciao" Ludovico
python send_to.py --from "iMessage;-;+39MITTENTE" "Ciao" Fede
```
- **Argomenti:** prima il testo, poi uno o più nomi (match su nome/cognome/rubrica, case-insensitive; alias tipo “mamma”/“mom”).
- **`--dry-run`:** mostra cosa farebbe senza inviare.
- **`--yes`:** salta la conferma interattiva.
- **`--vcf`:** carica contatti dal file invece che da macOS Contacts.
- **`--force`:** non richiede evidenza iMessage in `chat.db`; usa il primo telefono normalizzato o email (utile per numeri mai scritti prima).
- **`--sms-fallback`:** se iMessage fallisce, ritenta come **SMS** via Messages (serve *Text Message Forwarding* iPhone→Mac e “Invia come SMS” sul Mac).
- **`--from`:** stesso significato degli altri script; altrimenti usa `config.yaml`.
- **Nota:** `send_to.py` non scrive su `sent.json`; solo `send.py` è riprendibile tramite quel log.

## Config
Edit `config.yaml`:
- `filter.keywords` — match list
- `templates.{it,en}` — message text per language
- `rate_limit.*` — delays and caps
- `safety.skip_cold_contacts` — skip if zero past messages

## Files
- `output/preview.csv` — generated by scan, edited by user
- `output/sent.json` — append-only log, idempotent

## Risks
- 400 cold messages with low reply ratio = Apple spam profile. Defaults skip cold contacts and cap at 80/day. Monitor first batch (50) before scaling.
- `sent.json` records *attempted* sends. AppleScript returns success without confirming delivery. Verify the warm-up batch (50) actually arrived before scaling.
- Messages with NULL `text` (modern `attributedBody` blob) are skipped during language detection. Active chats may appear "cold" → language defaults to IT. If wrong language sent, fix template in `config.yaml` and re-scan.
